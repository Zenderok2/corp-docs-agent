Первый результат — импорт, FTS5, составной ответ и веб-экран. После него
проверить заметку по цитате, доступный стенд и контрольные случаи. При работе
вдвоём проверку хоста и сетевого доступа начать параллельно с импортом.
Гибридный поиск, расширенные роли и UI загрузки брать после основного сценария.

## Окна на 48 часов

| Время от старта | Проверяемый результат |
| --- | --- |
| 0–3 ч | Кик-офф, проверка форматов, эталоны, условия доступа жюри, выбор хоста |
| 3–10 ч | Файловый импорт двух наборов, SQLite, FTS5, locators |
| 10–18 ч | Составной ответ, конфликт, локальный chat и проверка ссылок в API |
| 18–25 ч | React с цитатами, форма практики и проверка сохранения |
| 25–33 ч | Стенд доступен извне. Проверка изоляции, агентский цикл, отдых/резерв |
| 33–39 ч | Контрольные случаи, повторный запуск, замеры для калькулятора. Сравнение FTS5/hybrid при наличии времени |
| 39–44 ч | Зафиксированная версия на стенде, запись видео, описание и расчёт запроса |
| 44–48 ч | Проверка ссылок и комплекта, публичный репозиторий к сдаче, резерв на отправку |

Отдых и резерв входят в окна. При нехватке времени оставить составной ответ
с цитатами, корректный отказ, сохранение примера и доступный стенд. Сохранить
время на калькулятор и отправку. Compose, корпоративные роли и гибридный индекс
зависят от готовности основного маршрута.

## Демонстрация и экономика

Задать составной вопрос на материалах задачи. Открыть оба источника,
показать найденную редакцию или исключение. Сохранить пример применения
по одному пункту и показать его в очереди проверки. При наличии времени
показать вопрос с конфликтом или нехваткой данных.

Замерить первичную индексацию, поиск и генерацию на запрос, включая повторы.
Внести тарифы и инфраструктуру по инструкции [калькулятора](operations/ECONOMICS.md).
Потенциальную выгоду считать по времени до проверенного ответа.

Сдать видео, описание, публичный репозиторий, URL стенда и калькулятор.
Живой показ на стенде требуется на финальном питче. [Чек-лист сдачи](preparation/KICKOFF.md#перед-сдачей).
