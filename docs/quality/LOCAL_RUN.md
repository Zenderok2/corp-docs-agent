# Локальный прогон 26 ноября 2026 года

Корпус из четырёх вымышленных документов и 21 индексируемого фрагмента.
Chat — Qwen3-4B-Instruct-2507 Q4_K_M в llama.cpp b12535, два потока CPU.
Для гибридного прогона использованы Qwen3-Embedding-0.6B Q8_0 и ChromaDB 1.3.5.

| Сценарий | FTS5 | FTS5 + Chroma |
| --- | --- | --- |
| Уточнение юрлица в новом вопросе | Запрошено | Запрошено |
| Ответ после уточнения | Две нужные цитаты, полный ответ | Две нужные цитаты, модель пометила ответ как частичный |
| Тип и срок лицензии подрядчика | Цитата из правил лицензирования | Цитата из правил лицензирования |
| Пропуск в офис, отсутствующий в корпусе | Запрос в очередь качества | Запрос в очередь качества |
| Повтор после публикации в очереди | Ответ службы качества | Ответ службы качества |

В прогонах с моделью наблюдались задержки от 4,4 до 56,1 с.
Сценарии пробела без вызова chat завершались за 0–0,3 с.
Это локальные замеры. Для стенда выбрана конфигурация FTS5, которая прошла
полный синтетический сценарий. Проверка на корпусе заказчика требует его
импорта и разметки контрольных вопросов.

Проверки без модели прошли отдельно. Покрыты координаты PDF/DOCX,
актуальность и ACL, сохранение истории и практики после перезапуска,
получение ответа службы качества и отзыв опубликованного ответа.
Через браузер проверены вопрос о лицензии, открытие исходного фрагмента
и отправка примера по цитате. [Инструкция прогона](../../evals/README.md).
