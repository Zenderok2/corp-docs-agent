# Что изменили ответы организаторов

## Кик-офф и чат задачи 26 ноября 2026 года

- Заказчик подтвердил четыре обезличенных действующих регламента проектов.
  Глоссарий из чата можно публиковать. Вопросы для проверки должны учитывать
  разговорные формулировки, сокращения и неполный контекст.
- Краткий ответ нужен со ссылкой на конкретное положение для каждого тезиса.
  Допустима тестовая почтовая цепочка с копией сотруднику и обновлением базы
  знаний из подтверждённого ответа службы качества.
- Организаторы допустили во время хакатона облачные API для inference и embeddings
  при использовании моделей с открытыми весами, совместимой лицензией и возможностью
  локального развёртывания. Объявлен ориентир до 128 ГБ для весов в квантизации Q4
  или выше. Проект использует локальные модели и раздельные адаптеры.
- Для сравнения экономики нужны фактические токены и стоимость одного запроса.
  Учитываются модель, несколько вызовов, индекс и аренда выбранного хоста.
