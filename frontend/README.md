# Интерфейс агента

Три раздела доступны из боковой панели. Вопрос агенту показывает ход
диалога, цитаты и передачу пробела в службу качества. Документы открывают
извлечённый текст по редакциям. Раздел службы качества предназначен для
проверки вопросов и примеров применения.

Из папки `frontend` запустите `npm ci` и `npm run dev`. Vite передаёт
`/api` и `/health` на `http://127.0.0.1:8000`. Команда `npm run build`
проверяет TypeScript и собирает production-ресурсы в `dist`.

В Docker статические файлы отдаёт Caddy. Интерфейс и API доступны с
одного origin. Шрифты, скрипты и иконки не требуют внешней загрузки
во время работы приложения.
