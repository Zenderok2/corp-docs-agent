# Данные нового кейса

Корпоративные документы поступят на кик-оффе. Прежние материалы поддержки
хранятся отдельно в архиве.

- `inbox/` — локальная площадка для разрешённых входных файлов; содержимое
  исключено из Git. Приложение в дальнейшем хранит оригиналы в `runtime/uploads/`.
- Внутри `inbox/` вести две папки, `regulations/` и `product_licensing/`.
  Форматы, реквизиты и правила разбора определить при получении материалов.
- `samples/` — только явно синтетические или разрешённые для публикации примеры.
- `runtime/` в корне — будущие SQLite, извлечённые блоки и локальные артефакты;
  рабочие данные не смешиваются с fixtures.

Перед импортом определить document family, название, источник, владельца,
область/юрлицо, редакцию, период действия и доступ. Отсутствующие значения
сохранять как неизвестные. Нельзя назначать действующую редакцию по имени файла.
Для оценки использовать выданные примеры вопросов и собственную разметку
источников. Отдельного тестового набора по FAQ не ожидается.
