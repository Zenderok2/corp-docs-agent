# Документы и каталог импорта

- `samples/` содержит шесть вымышленных документов для гостевого режима.
  [Каталог демо-корпуса](samples/catalog.json).
- `inbox/` предназначен для рабочего набора. Файлы и каталог импорта
  хранятся локально. В Git включена только пустая папка.
- При импорте оригиналы сохраняются в `APP_STORAGE_ROOT/originals`,
  а текстовые блоки с локаторами и метаданными записываются в SQLite.

Укажите название документа, редакцию, область действия и группы доступа
в каталоге. Подтверждённые даты и статус берите из материалов. Рабочие
регламенты обычно относятся к группе `staff`.

Форматы, примеры команд и правила редакций описаны в
[инструкции импорта](../backend/README.md#импорт-рабочего-корпуса).
