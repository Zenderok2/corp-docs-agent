# Будущий синтетический корпус

Пока примеры не создавались. Во время спринта подготовить небольшой корпус
с явной маркировкой «синтетический»: две редакции регламента, приказ о
делегировании, таблица ответственных, отменённый документ и письмо с
противоречащей неподтверждённой информацией. Сохранить эталонные источники
для каждого контрольного вопроса.

Эти примеры нужны для проверки поведения, а не для утверждений о процессах заказчика.
